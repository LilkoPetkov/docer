# `Go` Functions
```go
// Main entrypoint to the application

func main()
```

```go
// Test function with an object

func (t teststruct) t1(x, y int) interface{}
```

```go
// Test function, not useful in any way
//
// Args:
//
// x: the X value
// y: the Y value
//
// Returns:
//
// nill/void

func testFunc(x, y int)
```

```go
// This is a multiline comment
// and the function will have args on
// multiple lines

func testFunc(
	x,
	y int,
) (string, error)
```

```go
**UNDOCUMENTED**
func genericFunc[T any](x, y T) T
```

```go
**UNDOCUMENTED**
func (P testStruct) withObject(x int) string
```

```go
**UNDOCUMENTED**
func returnsError(x int) (bool, error)
```

```go
**UNDOCUMENTED**
func main(x, x, x int)
```

```go
// Main entrypoint // \\ to the program

func main(x, y int) string
```
